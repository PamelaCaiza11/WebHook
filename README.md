# Instructions

## Install dependencies:
Make sure you have pip installed and run:
```bash

pip install flask
```

If you need to enable CORS for the server, also install:
```bash
pip install flask-cors
```

## Running
### Start the Flask server:
Run the `webhook.py` file in your terminal or command line:
```bash
python webhook.py
```
This will start the server at [http://127.0.0.1:5000](http://127.0.0.1:5000).

### Open the HTML file:
1. Go to your project folder.
2. Open the `index.html` file in your web browser.

### Send data to the webhook:
1. Fill out the form in the HTML with a message and click "Send."
2. The server's response will be displayed on the web page.

### Check the terminal:
The data sent to the webhook will be printed to the terminal where the Flask server is running.
